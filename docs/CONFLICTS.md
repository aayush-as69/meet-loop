# Meetloop Conflict Detection

## Purpose

Meetloop keeps earlier decisions so a new meeting can be checked against existing decision memory.

## Conflict record

A detected conflict retains the earlier decision, the new decision, a reason and severity.

## Review semantics

A conflict is a review signal, not proof that two statements are objectively contradictory. The user remains responsible for deciding whether the new statement supersedes, clarifies or contradicts the old one.

## Recommended review flow

1. Read the old decision.
2. Read the new decision in its meeting context.
3. Inspect the reason/severity signal.
4. Decide whether the new decision supersedes the old one.
5. Confirm the final action only after the context is understood.
